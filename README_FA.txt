پروژه اندروید HACKER TRADER

این فایل APK نیست؛ پروژه آماده ساخت APK است.
۱. پوشه پروژه را در Android Studio باز کنید.
۲. منتظر بمانید Gradle Sync انجام شود (نیازمند اینترنت برای دانلود ابزارهای Android).
۳. از منوی Build گزینه Build Bundle(s) / APK(s) > Build APK(s) را بزنید.
۴. APK در app/build/outputs/apk/debug/app-debug.apk ساخته می‌شود.

بازی HTML اصلی در app/src/main/assets/index.html قرار دارد و آفلاین اجرا می‌شود.
پیشرفت بازی با localStorage در WebView ذخیره می‌شود؛ پاک کردن داده برنامه باعث پاک شدن ذخیره می‌شود.
آیکون بر اساس تصویر تأییدشده ساخته شده است.
